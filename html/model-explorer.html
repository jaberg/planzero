Model Explorer

Trace how variables flow between the model elements of one inference group.

PlanZero models are built from model elements, and each element declares the variables it defines and the variables it accesses. This page reads those declarations and presents them in two linked views: an Overview matrix of producer-to-consumer dependencies, and a Trace view for following a particular variable, element, or path. The explorer is an interactive companion to the Inference Groups section of the glossary and to the Models page.

Overview

Rows are producer elements and columns are consumer elements. A cell shows how many distinct variables flow from the row element to the column element. Hover a cell for the variable names, and click it to open exactly those dependencies in the Trace view.

Trace

Pick an element or variable as the focus, then choose a depth and a direction (upstream, downstream, or both). Click a node for its declarations. Carry variables and loop-carried this_carry accesses are drawn as dashed orange links.

Path finder

Choose a source element and a target element to list directed dependency paths. Click a path to isolate it in the graph. Enable carry links if the path should be allowed to use loop-carried reads.
