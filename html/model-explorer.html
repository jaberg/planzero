Model Explorer

Explore the interactions between model elements by inference group.

PlanZero models are built from model elements, which work by defining variables and accessing one anothers' variables. The Model Explorer visualizes those interactions. The Overview tab displays a matrix of producer-to-consumer dependencies. The Trace tab shows individual variable definitions and accesses in terms of the subphases of model construction. The explorer is an interactive companion to the Models page, which focuses on whole-model visualizations and metrics.

Overview

Rows are producer elements and columns are consumer elements. A cell shows how many distinct variables flow from the row element to the column element. Hover a cell for the variable names, and click it to open the Trace tab for that (producer, consumer) pair of elements. Alternatively, check elements to trace via the Trace column.
